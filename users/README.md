# Руководство пользователя

Deep — мессенджер с локально защищённой идентичностью и сменными транспортами. На текущей предрелизной точке Android и Windows проходят физическую UAT-проверку; устанавливать тестовые сборки следует только по приглашению команды.

## Основные понятия

- **Deep ID** — идентификатор аккаунта. Передавайте его собеседнику целиком; приложение показывает и копирует ID одной строкой.
- **Recovery phrase** — единственный материал для восстановления аккаунта. Она не должна попадать в скриншоты, чаты поддержки, логи и облачные заметки без вашего осознанного шифрования.
- **Транспорт** — способ доставки зашифрованных данных. Текущая UAT-сборка использует XPoint; это не означает, что XPoint является единственно возможным транспортом.
- **Путь** — фактический маршрут текущей сетевой операции. Он отображает используемый транспорт и узлы, а не обещает ручной выбор ещё не подключённых режимов.

## Безопасное начало

1. Получите сборку и контрольные данные только из официального UAT/релизного канала.
2. Создайте аккаунт или восстановите его по recovery phrase.
3. Сохраните recovery phrase офлайн до начала переписки.
4. Сверьте Deep ID с контактом через независимый канал.
5. Не отключайте защиту снимков экрана без необходимости.
