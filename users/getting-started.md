# Первый запуск

## Создать новый аккаунт

1. Откройте Deep и выберите создание аккаунта.
2. Задайте отображаемое имя.
3. Дождитесь завершения инициализации защищённого локального хранилища.
4. Откройте 24-word Deep Recovery Phrase, перепишите её без скриншота и подтвердите сохранение.
5. Скопируйте постоянный Deep ID из профиля или покажите его QR. Он не имеет
   срока действия, восстанавливается из Deep Recovery Phrase и разрешает
   текущий подписанный contact bundle; одного отображаемого имени для связи
   недостаточно. Для одноразовой передачи можно отдельно создать expiring QR.

Создание account, phrase, device keys и локальной базы не требует сети.
Отсутствие Registry/XPoint/bridge не может превратить этот этап в ошибку
запуска. Сеть нужна только для публикации device/prekey bundle, mailbox
enrollment и обмена сообщениями. Новый clean-break generation ещё должен
пройти physical airplane-mode gate и поэтому пока не считается выпущенным.

## Восстановить аккаунт

Выберите восстановление и введите все 24 слова точно, не отправляя их через
буфер удалённой поддержки. Phrase восстанавливает account authority и тот же
постоянный Deep ID, после
чего создаётся новое устройство с новыми device keys. Старые device keys не
копируются. Восстановление не гарантирует возврат истёкших server messages,
contacts, chat/group history, XUR routes, one-time invites, outbox, локальных черновиков, кэша
или вложений. Для них нужен authenticated encrypted backup или transfer с
действующего устройства. «Восстановить account» не означает «восстановить все
чаты».

## Начать диалог

1. Получите постоянный Deep ID/QR или одноразовый invite QR собеседника через доверенный канал.
2. Создайте новый диалог и вставьте адрес либо отсканируйте QR.
3. Проверьте короткий identity fingerprint до принятия первого контакта.
4. Не считайте отображаемое имя доказательством личности: оно не уникально.

Первое сообщение помещается в отдельный encrypted contact-request rendezvous,
поэтому для него не требуется уже существующий диалог или актуальный PRA.
Примите запрос только после проверки отправителя; заблокируйте его, если
контакт нежелателен.

## Поддерживаемые платформы этой версии

| Платформа | Минимум | Состояние текущей приёмки |
| --- | --- | --- |
| Android | Android 9 / API 28 | физический UAT выполняется |
| Windows | Windows 10 build 19041 | физический UAT выполняется |
| iOS/iPadOS | target 15.0 | не проверено; release support не заявлен до macOS authority и device evidence |
| Mac Catalyst | target 15.0 | не проверено; release support не заявлен до macOS authority |

Apple lane имеет статус `unverified` и `non-blocking` для текущего Android/Windows RC, но наличие target framework не считается поддержкой. Телефон с Android ниже API 28 не поддерживается этой сборкой.
