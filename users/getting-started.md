# Первый запуск

## Создать новый аккаунт

1. Откройте Deep и выберите создание аккаунта.
2. Задайте отображаемое имя.
3. Дождитесь завершения инициализации защищённого локального хранилища.
4. Откройте recovery phrase, перепишите её без скриншота и подтвердите сохранение.
5. Скопируйте Deep ID из профиля. ID отображается одной строкой; перенос на экране не меняет его значения, но копировать следует штатной кнопкой.

## Восстановить аккаунт

Выберите восстановление и введите recovery phrase точно, не отправляя её через буфер удалённой поддержки. Восстановление возвращает идентичность аккаунта, но не гарантирует возврат всех локальных черновиков, кэша, неподтверждённых вложений или ещё не доставленных данных со стёртого устройства.

## Начать диалог

1. Получите полный Deep ID собеседника через доверенный канал.
2. Создайте новый диалог и вставьте ID.
3. Проверьте ID до отправки первого сообщения.
4. Не считайте отображаемое имя доказательством личности: оно не уникально.

Сообщение от неизвестного контакта может появиться как запрос. Примите запрос только после проверки отправителя; заблокируйте его, если контакт нежелателен.

## Поддерживаемые платформы этой версии

| Платформа | Минимум | Состояние текущей приёмки |
| --- | --- | --- |
| Android | Android 9 / API 28 | физический UAT выполняется |
| Windows | Windows 10 build 19041 | физический UAT выполняется |
| iOS/iPadOS | 15.0 | требуется отдельная macOS/device-приёмка |
| Mac Catalyst | 15.0 | требуется отдельная macOS-приёмка |

Телефон с Android ниже API 28 не поддерживается этой сборкой.
