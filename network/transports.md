# Транспортные режимы и «Путь»

## Матрица режимов

| Режим | Ownership | Текущее состояние |
| --- | --- | --- |
| XPoint / authenticated MAU2 | `official-managed` | основной UAT и релизный профиль |
| authenticated MAU2 | `user-managed` | поддержан архитектурным контрактом; нет готового пользовательского release profile |
| Direct P2P | `direct-p2p` | не готов: verified direct peer implementation отсутствует, запуск fail-closed |

Нельзя смешивать protocol и ownership. Direct P2P допустим только с `direct-p2p`; authenticated MAU2 — только с `official-managed` или `user-managed`. Неизвестные и несовместимые пары отклоняются при запуске.

## XPoint

XPoint строит путь через несколько различных узлов. Клиент получает проверенный topology/membership material, выбирает маршрут и устанавливает Reality/VLESS ingress к узлам. Relay contact и маршрутные данные подписаны; generic HTTP endpoint не может незаметно заменить verified node.

Узел видит только необходимую ему часть маршрута. Storage получает зашифрованный mailbox payload. Файлы шифруются клиентом до загрузки в отдельный сервис.

## Direct P2P

Целевой режим предназначен для прямого обмена между проверенными peers, включая локальные технологии Wi‑Fi и Bluetooth там, где платформа даёт безопасную реализацию. В коде есть platform discovery/radio scaffolding, но нет завершённого transport adapter, который удовлетворяет контрактам аутентификации, приватности метаданных, outbox и подтверждений.

Поэтому Direct P2P нельзя включать подменой URL или обычным HTTP-сервисом. До завершения физической приёмки режим считается недоступным.

## Страница «Транспорты»

Страница показывает фактическое состояние активного транспорта:

- клиент;
- выбранные промежуточные узлы;
- назначение;
- состояние соединения и обновления маршрута.

Она не должна называться рекламной страницей сети и не содержит действия «поддержать сеть». Когда появится больше готовых транспортов, здесь должны отображаться доступность, политика выбора и текущий путь для каждого режима. Пока ручной selector не обещается.
