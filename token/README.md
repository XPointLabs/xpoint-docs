# XPNT и стейкинг

XPNT используется для регистрации и экономической ответственности узлов XPoint. Контракты развёрнуты в Arbitrum One, однако пользовательский production onboarding сети ещё не открыт. Наличие контракта не означает, что клиент или узел уже выпущен для общего использования.

## Проверочные параметры

| Поле | Значение |
| --- | --- |
| Сеть | Arbitrum One |
| Chain ID | `42161` |
| XPNT | `0x63B2cdb8B0d8774F1Fdca91D24803698582a079F` |
| Требование для узла | `25 000 XPNT` |
| Atomic requirement | `25000000000000` |
| Максимум contributors | `10` |
| Quorum signature | BLS12-381 |

Перед любой транзакцией сверяйте сеть, адреса контрактов, состояние onboarding и источник ссылки независимо. Документация не является финансовой рекомендацией.

Подробности: [Контракты](contracts.md), [Регистрация, награды и выход](staking.md).
